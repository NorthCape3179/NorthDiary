# NorthDiary

*A Personal Archive of Memories*

**记录时间，留存记忆。**

NorthDiary 是一款 Windows 本地图文日记与个人文集软件。用文章保存日常，用时间线整理往事，用人物档案串联故事，让零散的记忆逐渐形成属于自己的个人档案。

[下载安装 v1.7.0](https://github.com/NorthCape3179/NorthDiary/releases/tag/v1.7.0) · [v1.7.0 更新日志](docs/RELEASE-v1.7.0.md) · [开源许可证](LICENSE)

## 下载与安装

1. 打开 [Releases 发布页](https://github.com/NorthCape3179/NorthDiary/releases/tag/v1.7.0)，下载 **`NorthDiary-Setup-v1.7.0.exe`**。
2. 双击安装，可选择程序安装位置及是否创建桌面快捷方式。
3. 启动 NorthDiary，开始记录。程序默认沿用已有的默认数据目录；首次没有默认数据库时，可选择已有日记目录或新的空目录。

安装版面向 Windows 10 / 11 x64，无需另行安装 Python。安装包约 65 MiB，目前未数字签名，Windows 可能显示“未知发布者”。发布页同时提供源码 ZIP 和 SHA256 校验文件。

## 软件特色

### 图文记录与文集整理

- 创建和编辑文章，支持基础加粗、斜体、段落缩进与只读阅读。
- 支持正文图片、图注、照片板、图片查看与附件托管。
- 使用分类、普通标签和临时标签整理内容，支持标题及正文搜索、置顶与排序。
- 文章总览可跨日期浏览、按分类排列和筛选；回收站支持恢复与永久删除。
- 停止输入约 0.9 秒后自动保存，切换文章和正常关闭前再次保存。

### 沿着时间回顾记忆

- 支持完整日期，也支持只记得年份或月份的模糊日期。
- 主界面时间轴用于浏览日期，时间线总览按时间串联文章。
- 随机回忆提供带背景的只读正文和照片板，可继续查看另一篇。
- 季节背景随文章日期变化，昼夜效果随深浅主题切换。

### 让人物拥有独立档案

- 记录姓名、代号、出生日期、相遇时间与相遇方式，支持搜索、置顶和星标。
- 普通与临时关系标签以不同颜色区分。
- 一篇文章可关联多个人物，人物详情显示相关文章；修改姓名或代号不会破坏已有编号关联。
- 可在正文光标处快捷插入人物代号。**插入代号文字不会自动添加人物标签。**

### 导出、交换与本地保存

- 将所选文章导出为 EPUB，支持章节排序、目录和正文引用图片。
- 导入 NorthDiary 专用 EPUB，可恢复文章、模糊日期、分类标签、正文图片及关联人物资料；重复内容跳过，冲突保留副本。
- 通过独立的私有 GitHub 数据仓库手动上传、下载文章包，每包最多 20 MiB。
- 使用本地 SQLite 数据库保存记录，提供完整 `.ndiary` 备份导出及数据库升级前快照。

### 界面与个性化

- 三栏原生桌面窗口，支持多种配色、深浅主题切换与季节背景。
- 右上角工具区可折叠，并记住展开状态。
- 软件详情页集中展示产品介绍、版本信息和更新日志。

## 数据、备份与升级

默认数据目录通常为：

```text
%LOCALAPPDATA%\NorthDiary\NorthDiary
```

实际使用的路径可在主窗口底部查看，或点击“数据文件夹”打开。

| 内容 | 用途 |
| --- | --- |
| `northdiary.sqlite3` | 文章、分类、标签、附件记录、人物资料及关联。 |
| `attachments/` | 软件复制保存的附件文件。 |
| `ui.ini` | 界面设置。 |
| `backups/` | 数据库升级快照（如已生成）。 |

更新前请使用软件内的“导出备份”，随后正常关闭程序。更新时沿用原数据目录即可保留记录；不要用空目录替换原数据目录，也不要只复制运行中的 SQLite 主文件作为备份。

人物功能使用 schema v4，首次升级前会生成数据库快照。**旧程序不能直接打开升级后的同一数据库；回退须使用升级前快照的副本数据目录。** 强制结束进程仍可能丢失尚未自动保存的修改。

## 当前范围

- EPUB 导入仅支持 NorthDiary 自己的专用格式，不适配外部 EPUB；v1.1 的旧导出文件需要用新版重新导出。
- EPUB 文章包仅交换正文引用的图片，不包含未在正文引用的独立附件。
- GitHub 功能为手动文章包交换，不提供自动双向同步、删除传播或整个数据库覆盖。
- 人物目前使用默认剪影头像，暂不支持自定义头像照片。
- `.ndiary` 备份导出已提供，自助备份恢复界面尚未完成。
- 自动备份、PDF 导出及完整编辑排版工具尚未提供。

## 从源码运行

需要 Python 3.11–3.13。下载并解压源码后，在项目文件夹中双击 `start.cmd`；首次运行会创建虚拟环境并联网安装依赖。

也可以在项目根目录的 PowerShell 中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

指定独立数据目录：

```powershell
.\.venv\Scripts\python.exe main.py --data-dir D:\NorthDiaryData
```

展示用途可在安装依赖后运行 `start-demo.cmd`，在工程内独立的 `demo-data` 目录中生成并打开虚构数据。该目录非空时，生成脚本会停止，避免覆盖已有内容。
