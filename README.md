# NorthDiary

## 范围切换、照片选择与文章总览

日期行按钮根据当前状态显示“全部日期 / 当前日期”，可反复切换。照片板单击选中，选中相纸边使用主题色；双击才打开大图，正文图片引用仍可单击打开。分类改为下拉单选，“＋”新建并选择分类；标签继续支持多选。旧文章多个分类在右侧显示最后一个，下一次保存将按单分类规则保存。

时间轴按下不缩放，拖动前三天保持原刻度，超过三天后才缩放。左下角“文章总览”位于回收站上方，弹窗可跨日期搜索、按创建时间/修改时间/标题等排序，并双击或用“打开文章”返回编辑。排序控件从左侧移入总览，选择仍会同步主列表并记住。

## 日期选择与配色扩充

日期框可直接输入 2026-07-15、2026/7/15、20260715，按 Enter 或离开输入框确认。旁边的小日历按钮打开自定义日历，可输入日期、切换年月、点选日期，再点确定。无效日期会提示并保留原日期；时间线轻点也使用这套日历，拖动浏览仍保留。日期控件和时间轴指针已缩小。

配色共八套：鼠尾草绿白（原浅色）、灰黑夜色（原深色）、浅咖米白（原奶油米白）、黑红夜色（灰黑底、黑红按钮）、酒红米白、橙绿米白、蓝与纯白、灰与浅灰。主题与原来的季节/昼夜背景规则联动，深浅快捷切换会记住最近使用的浅色配色。

## 全部文章排序与新增主题

默认跨日期显示全部文章，按创建时间最新优先。左侧排序支持创建时间最新/最早、修改时间最新/最早、标题升序，并记住上次选择。置顶始终在前，置顶组内部同样遵循当前排序。搜索、分类、标签过滤后仍使用同一排序。“所选日期”继续支持单日查看；“最近打开”保留打开时间顺序。“手动排列”保留拖动排序，其余排序模式禁用拖动以免规则冲突。

右上角主题下拉新增“奶油米白”“红酒夜色”，原浅色和灰黑深色保留，共四套主题。主题选择会记住；深浅快捷按钮在原两套之间或奶油/红酒之间切换。浅色季节背景减少淡化，深色背景透明度参数不变。季节仍跟随文章日期，昼夜跟随主题。

## 季节背景

图钉旁的山景图标可独立显示/隐藏中间区域的季节背景，并记住选择。图片只作界面装饰，不写入文章。按当前打开文章的日记日期切换（空白页按所选浏览日期，无选择时按今天）：3–5 月春、6–8 月夏、9–11 月秋、12–2 月冬；浅色主题使用白天图，深色主题使用黑夜图，切换主题立即更新；不按钟点切换昼夜，切换文章或修改日记日期立即更新季节。图像在中间区域下半部显示，整体降低透明度并向上渐隐，缩放不拉伸。八张素材已复制到 northdiary/resources/backgrounds，无须依赖原始图片文件夹。

## 左侧文章模式

左侧日期后新增“日期全部文章 / 最近打开”下拉。默认按今天或时间线选定日期浏览；“全部日期”可取消日期限制。最近打开模式跨日期按打开先后排序，置顶文章仍在最前，分类和标签筛选继续生效。打开记录保存在数据目录 ui.ini 中，最多保留 200 篇，重启可继续使用；最近模式采用自动排序，手动拖动请切回日期模式。选择时间线日期会自动回到日期模式。

工具栏压缩到 28 像素高，图钉仅显示图标。下拉弹层禁止关闭点击被回传重放，再次点击同一个按钮会直接收起。

## 深浅主题与状态联动

右上角“深色模式 / 浅色模式”切换界面并保存选择；“数据文件夹”打开实际日记存储位置。下拉使用自定义弹层，按照控件当前宽度和 Qt 逻辑像素布局，避免 Windows 缩放下原生菜单选中框错位。按钮波纹透明绘制，跟随按钮 resize 调整覆盖范围。

阅读模式会先保存，失败则保持编辑；格式按钮反映光标处的加粗/斜体状态；图片工具根据图片选中情况、正文入口存在与阅读模式启用或禁用。主题切换只改界面，不改正文存储。

目前适合小规模日常记录与试用，尚缺备份恢复界面、自动备份、内容历史和完整编辑排版工具。大量迁入旧日记前，优先完成恢复流程；现有“导出备份”生成数据库和附件的完整快照，EPUB 暂缓。

## 回收站与交互更新

回收站入口移到左下角，点击打开独立弹窗。每行显示文章、日记日期和删除时间，点击行查看预览；行尾可恢复或永久删除。永久删除有二次确认，只清理软件托管附件，不删除原始文件。按钮增加轻微扩散反馈，下拉菜单统一浅色背景。

左侧排序拖动时，条目只在列表框内浮于上层，落点线提示位置，下方排列保持不动；松手才提交新顺序。

## 置顶与固定顺序

编辑区顶部独立一行提供图钉按钮，可同时置顶多篇文章。左侧列表置顶文章在前，普通文章在后，拖动可分别调整两个区内的顺序；跨区拖动不会改变置顶状态，请用图钉操作。新文章追加到普通区末尾，新置顶文章追加到置顶区末尾。筛选时排序只调整可见文章占用的位置。文章正文修改和日期修改不会自动重排。数据库升级到 v3 前会自动保留旧数据快照。

## 标签更新

右侧下拉可选普通标签；“＋”菜单可创建普通标签或仅当前文章可见的临时标签。普通标签保存后进入公共列表，以后可直接选择；临时标签不会出现在右侧候选或左侧筛选中。“×”只移除当前文章关联，普通标签仍可复用。左侧标签筛选可与分类、搜索和日期组合使用。升级至数据库 v2 时自动保存 v1 数据库快照到数据目录的 backups 文件夹；无须重建数据。

## 本轮更新：图片导航与时间线

新插入图片在正文显示小入口，点击入口或右侧缩略图查看大图，可放大/缩小、适应窗口、前后翻图。图片栏支持说明、定位正文、重新放置入口和移除入口（保留文件）；旧版正文内嵌图片继续兼容，不自动改写。

日期后增加时间线：拖动选择浏览日期，指针先在中心小范围移动，超过后刻度轴跟随；轻点打开日历。选中日期筛选文章，不改写文章日期；点“全部日期”取消筛选。在选定日期下新建文章，日记日期默认为该日。当前先提供右侧图片栏，下侧布局待后续接入。

## 启动

安装 Python 3.11–3.13 后，双击 `start.cmd`。首次启动会在工程目录创建独立 `.venv` 并安装锁定版本的 PySide6，需要网络。后续离线启动。

PowerShell 手动启动：

```powershell
cd D:\NorthDiary
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

PyCharm 可直接打开工程，把解释器设置为 `.venv\Scripts\python.exe`，运行 `main.py`。

## 数据目录

默认使用 Qt 的 Windows 本地应用数据目录（通常是 `%LOCALAPPDATA%\NorthDiary\NorthDiary`），窗口底部显示实际路径。数据不在工程或 EXE 内。

```powershell
.\.venv\Scripts\python.exe main.py --data-dir D:\NorthDiaryData
```

数据目录包含 `northdiary.sqlite3`、SQLite 日志、`attachments/`。运行时请使用应用的“导出备份”；不要只复制正在使用的 SQLite 主文件。当前恢复仅通过开发测试验证，自助恢复界面待实现。

## 开发结构

`ui/` 负责界面；`storage/` 管理 SQLite 与关系；`services/` 管理附件、备份和导出契约；`models.py` 定义数据对象；`app.py` 负责启动和组装。无浏览器、网页服务器或云端日记依赖。
