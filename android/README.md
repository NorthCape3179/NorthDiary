# NorthDiary 安卓端 0.1.1-alpha

原生 Android 应用，与 Windows 客户端并列放在本仓库。使用 Java 17、Android 原生视图和 SQLite，无运行时第三方依赖，不使用网页应用框架。

## 0.1.1 界面与主题修复

- 统一米色与红酒浅色、暮色酒红深色的圆角卡片、线条图标、胶囊筛选和底部导航。
- 重排文章列表、折叠编辑整理区、人物卡片和分组设置；图片仍只显示文件名链接。
- 主题在 attachBaseContext 中解析，避免 onCreate 内资源已加载后调用 applyOverrideConfiguration 引发崩溃；选择先落盘，再重建界面。
- 新增真实主题选择器回归：深色/浅色/跟随系统多次切换、重新启动保持深色、检查实际资源颜色和数据库内容。
- UI 截图仅使用自动测试生成的虚构记录。
- 交付 APK 的构建增加调试密钥缓存。0.1.0 的初次调试构建未成功保存密钥，新 APK 可能无法覆盖旧版；遇到签名冲突时，先从旧版导出 .ndiary 备份，再卸载安装并恢复。缓存仍不替代正式发行签名。

## 已实现的初版代码

- 手机单栏；可用宽度达到 840dp 时文章列表与正文左右分栏；支持横竖屏、分屏及系统栏/软键盘避让。
- 新建、阅读、编辑、移入回收站和恢复；新文章先进入待确认，完成后可确认。
- 基础段落、加粗、斜体；标题及正文搜索、标签编辑和筛选、事件时间/创建时间排序。
- 图片复制到应用私有目录，以文件名链接显示，不生成缩略图；点击通过临时只读授权交给系统图片查看器。卸载应用会删除本地资料，卸载前请导出完整备份。
- 年、年月、完整日期；沿用桌面 YYYY-未知-未知、YYYY-MM-未知 格式；时间线之外阅读时隐藏事件日期。
- 人物姓名、唯一代号、出生日期、相遇日期、简介/相遇方式；文章人物多对多关联，人物页列出三个空间内的相关回忆；删除人物保留文章。
- 停止输入约 0.9 秒自动保存；编辑日志使用 AtomicFile；保存失败保留日志并阻止页面跳转；旋转后恢复文章、编辑状态和正文滚动位置。
- 跟随系统、米色红酒浅色、深色主题。
- .ndiary 完整备份导出与恢复。恢复先在独立目录解压并检查格式、schema v7、完整性、外键及附件，再切换活动目录；恢复前目录保留。

## 与桌面端的数据关系

数据库建表来自桌面 v1.7.5-beta 的 `northdiary/storage/database.py`，user_version=7，保留分类、临时标签、置顶、排序、关系标签等未在安卓 UI 开放的字段和表。编辑文章时只更新已实现的字段；不复制文章，也不删除未显示的分类或关系标签。

备份沿用 `manifest.json`（format=NorthDiary, version=1）+ `northdiary.sqlite3` + `attachments/`。只支持 schema v7 的完整包；恢复是整体切换，**不做合并或自动同步**。Windows 的备份恢复 UI 尚未实现，不能据此声称两端已有一键双向同步；跨端往返仍需真机与桌面联合验收。

正文未修改时保留原始 HTML；修改正文会转换为手机基础排版。含 Qt 样式/表格的文章进入编辑前显示提示，建议先导出备份。图片不在列表或正文中内嵌展示；正文保留 `ndiary-image:` 引用，下方始终提供已托管附件链接。外部图片不自动下载。

## 构建

工具链固定为 AGP 8.7.3、Gradle 8.9、JDK 17、compile/target SDK 35、min SDK 26（Android 8.0）。首次安装依赖需要联网。

在安装 Android SDK 与 Gradle 8.9 的环境中，在本目录执行：

```sh
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
gradle :app:connectedDebugAndroidTest
```

源码工程尚未包含 Gradle wrapper；请使用 Gradle 8.9。仓库 Actions 的 **Android alpha** 流程自动配置工具链，生成 `NorthDiary-android-0.1.1-alpha` artifact，里面的 `app-debug.apk` 可安装。调试签名缓存失效时，后续 APK 可能无法直接覆盖安装；请先备份，正式发布前需配置持久发行签名。

## 验证范围

- JUnit：模糊日期规范化、闰年及非法输入。
- Android instrumentation：真实 SQLite 保存回滚及重试、标签搜索、人物关联、时间线之外、回收站、失败编辑日志及原子文件恢复、桌面专属字段保留、备份往返、缺失附件及路径穿越拒绝。
- 手机与平板 emulator 配置：pixel_2、pixel_c，手机 API 34 / 平板 API 30，验证编辑页的单栏/双栏选择及 Activity 重建后恢复未完成的日期输入。
- 尚需用户真机验收：中文输入法、长文编辑、横竖屏与多窗口交互、图片外部查看器、系统文档选择器及跨端备份包。

## 初版限制

- 暂无 GitHub 文章包交换、EPUB、随机回忆、四季背景、自定义人物头像、分类/关系标签管理、永久删除。
- 完整备份解压后最多 200 MiB、最多 10000 项；单张图片最多 32 MiB。
- 备份恢复前目录保留于应用私有数据目录，可在设置中切回上一次恢复前档案，暂未提供旧目录清理 UI；恢复过程中若旋转导致页面重建，本次后台任务的结果不会自动应用，需要重新操作。活动档案仍受保护。
- SQLite 小规模编辑事务在界面线程执行，图片和备份处理在后台；大量记录性能尚未验收。
- alpha 不等于正式发布：只有构建日志通过才能声称编译成功，模拟器通过不代替手机/平板体验验收。
