# AI 工作室第三、四阶段 · 轻量版

日期：2026-11-02。沿用已接入的 DeepSeek 和本地对话记录，数据库仍为 SQLite，schema 保持 v8，不增加迁移。

## 赏析与分析

- 文字赏析按文学点评、情感点评、读者视角、逐段批注使用不同的具体任务要求。
- 逐段批注以已选正文的非空段落编号，在回复中呈现“文章标题 / 第 N 段 / 摘录 / 批注”，不修改原文。
- 深度分析支持人物、事件、跨时间变化、文章关联；可填写分析对象或关注的问题。
- 人物分析不读取人物档案；材料只来自本次已选文章。事实、推测、未知需明确区分。

## 故事创作

“类型”继续选择小说、轻小说、散文、多视角等；新增“步骤”选择直接创作、故事大纲、人物设定、生成章节、续写下一章、连续性整理、整合现有章节。

“故事设定”里可填写名称、大纲、人物设定及连续性备忘。建议流程：

1. 选择文章或填写创作要求，生成故事大纲。
2. 打开故事设定，点“填入最近生成的设定”应用大纲；人物设定和连续性整理的结果也可这样填入。
3. 选择“生成章节”，指定章数，确认发送。
4. 一章完整生成后章数自动前进；选择“续写下一章”继续。

设定随发送后的请求保存于当前对话，不创建或修改人物档案；打开旧对话会恢复当时的设定。未发送的设定仅在当前窗口内保留。
新对话与更换文章范围会清空该对话的任务设定，旧记录保留。每次发送预览仍可检查文章、设定与历史消息。
允许只填写创作要求或故事设定进行原创创作，不强制提供日记；虚构内容与真实记录分开。

## 本轮边界

不做自动连写整部长篇、复杂人物管理、自动长期记忆、原文侧边批注气泡、AI 作品库入库或 Android。生成效果由用户验收。

## 连接弹窗修复

此前 Qt 自动选择 OpenSSL 时可能加载 MySQL 目录里的不兼容 DLL。Windows 现于联网前明确使用系统 Schannel TLS，保持证书校验，不修改 MySQL 或系统 PATH。日记数据库从未改成 MySQL。
关闭旧窗口并重新启动脚本版后生效。

## 验证约定

按用户要求只做启动、关键入口与请求准备的简短检查，不运行全量测试或实际生成验收。
