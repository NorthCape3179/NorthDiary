# 午夜电台主题

在右上角「外观与主题」中选择「午夜电台」。软件会记住选择；切换浅色再切回深色也会恢复这套主题。

- 深蓝金属面板、青色高光、扬声器格栅与信号波形均由 Qt 原生绘制，没有新增图片下载或素材授权依赖。
- 时间轴右侧旋钮可按圆周拖动，顺时针向未来、逆时针向过去。方向键和滚轮每格一天，Page Up / Down 每格一周。时间轴仍支持原来的直接拖动与日历。
- 旋钮使用现有日期浏览流程和保存保护，不直接修改文章日期。日期切换仍采用节流预览；释放旋钮或停止键盘、滚轮操作后提交最终日期。
- 开启现有歌词显示后使用电台屏幕样式，继续使用网易云播放信息、真实进度、暂停状态、原文和译文。波形只是装饰，不能代表实时音频频谱；暂停或进度未知时不滚动波形。
- 字体、局部文字格式、照片大小与原比例显示不随主题改变。季节背景偏好保留，电台主题内使用控制台背景，切回其他主题恢复季节背景。

验证：38 项主题、时间轴、字体、窗口、文章列表检查和 3 项日历检查通过；Windows 临时数据窗口确认主题菜单、旋钮拖动、方向键调谐以及切回普通主题正常。测试未修改个人日记数据。
