# NorthDiary v1.8.2

**人物照片、正文头像插入，以及两套全新主题。**

发布日期：2026-11-17。本版基于 v1.8.1，保留图文记录、时间线、AI 工作室、同步歌词、秋日湖畔和 EPUB 交换功能，继续完善人物资料与记录体验。

## 人物照片与头像

- 人物档案支持自定义头像，可恢复默认剪影；头像采用圆形显示。
- 人物详情支持批量添加照片、查看大图、前后切换、缩放、设为头像和移除照片。
- 正文人物引用可选择代号或头像，头像以 24×24 像素的圆形副本插入。
- 已插入的头像是当时的副本，之后修改人物头像或删除档案不会改写文章里的头像。
- 阅读、随机回忆、EPUB 导入导出和 GitHub 文章包支持相应的人物图片资料。
- 每位人物最多 100 张照片，编码总量最多 32 MiB；照片为托管浏览副本，不修改原文件。

## 图片导入与阅读

- 插入图片时可选择“保留原图”或“自动压缩”；自动压缩大图最长边不超过 2560 像素，保留透明背景。
- 压缩结果更大、或图片为动图时保留原图。
- 优化照片板尺寸与原图比例、图片说明和阅读布局；正文人物头像不再混入普通照片展示。
- 改进编辑工具栏、字体选择、日期面板与文章列表的细节表现。
- 优化文章列表的平滑滚动、时间轴日期浏览和日历中的文章标记。

## 午夜电台主题

- 新增深蓝金属面板、青色高光、扬声器格栅与电台歌词屏幕。
- 时间轴旁的调谐旋钮可拖动选择浏览日期，也支持方向键、滚轮和 Page Up / Down。
- 调谐仅切换浏览日期，不改写文章日期，继续使用保存保护和节流预览。
- 装饰波形不代表实时音频频谱；歌词仍使用现有播放信息、进度和译文。

## 纸间来信主题

- 新增米色信笺、纸纤维纹理、装订线、折角、邮戳和植物装饰。
- 正文横线跟随文字排版基线及滚动，兼容局部字号和原有文字格式。
- 照片板采用纸纹与胶带风格，歌词使用浅色便笺。
- 主题装饰仅用于显示，不写入文章正文，也不进入 EPUB。
- 两套新主题可记住选择；切回原有主题后保留季节背景偏好。

## 下载与运行

下载本发布页的 **`NorthDiary-v1.8.2-script.zip`**，完整解压到独立程序文件夹。

需要 Windows 10 / 11 x64 和 Python 3.11–3.13，双击 `start.cmd` 启动；首次运行会创建虚拟环境并联网安装依赖。已有虚拟环境应先执行 `.venv\Scripts\python.exe -m pip install -r requirements.txt` 更新依赖。

本版提供完整源码及脚本版 ZIP，**不包含 v1.8.2 EXE 安装包**；旧版安装包不代表本版功能。秋日湖畔所需的本地场景文件、字体与第三方声明随脚本包提供。发布文件不包含个人日记、数据库、附件、备份、账号或令牌。

## 数据兼容性与升级

- 程序版本：**v1.8.2**；数据库版本：**schema v10**。
- 人物图片使用新增的 `person_media` 表。旧库升级前生成 `before-v10-*.sqlite3` 数据库快照；原有文章和人物记录保留。
- 更新前建议导出完整 `.ndiary` 备份，正常关闭旧程序，再用新版沿用原数据目录。
- **旧程序不能直接打开升级后的同一数据库。** 回退需要使用升级前快照的副本数据目录，并保留完整附件。
- EPUB 仅接受 NorthDiary 专用格式；人物图片仍受清单大小和 20 MiB GitHub 文章包上限约束，过大时会明确报错。
- GitHub 为手动文章包交换，不是自动双向同步。AI 请求和在线歌词需要相应服务；它们不等同于完全离线功能。

更多操作见 [人物照片与头像说明](PEOPLE_PHOTOS.md)、`docs/midnight-radio-20261117.md` 与 `docs/paper-letter-20261117.md`。

## 验证情况与已知限制

本次对上传前的功能源码运行全量回归：**280 项中 263 项通过，9 项失败、6 项错误、2 项跳过**，不是全绿。

- 错误包含五个旧数据库迁移夹具遗留 `ai_works` 表导致重复建表，以及一项旧侧栏控件引用。
- 失败覆盖旧 AI 表集合、GitHub 连接界面、EPUB 反斜线路径校验、整篇缩进数值、顶栏数量/时序、主题数量，以及主窗口版本显示的旧断言。
- 主窗口现不显示版本号；版本测试已适配当前标题，并继续严格核对程序常量和详情页的 v1.8.2，单独复检通过。未将其余问题描述为已修复。
- 新增功能定向检查 43 项，41 项通过、2 项失败；其中上述标题断言已修正复检通过，另一项是电台旋钮的 350 毫秒提交时序断言。该旋钮项在全量运行中通过，仍保留时序不稳定的记录。
- 人物头像/照片、正文头像引用、图片压缩、纸间来信、平滑滚动等相关定向用例通过。全部 130 个 Python 文件编译检查通过。

部分断言与现有界面或 schema 已不同，部分问题仍需进一步定位，不能将所有失败均归为测试过时。建议先备份，并用副本数据目录试用新版本。

本版未制作和验证新版 EXE，也未在干净 Windows 环境完成全功能人工验收。字体、显示缩放、显卡和外部音乐软件版本可能影响实际体验。自动同步、自助备份恢复、PDF 导出等未完成能力不作为本次新增功能发布。
