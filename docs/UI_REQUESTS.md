# 后续界面功能需求

记录日期：2026-10-30。来源：用户新增的三项需求及年/月分隔补充。v1.4 已实现客户端界面并验证交互；Windows 实机与原始背景显示仍待验收。具体规则见 UI_V14.md。

## 1. 时间线总览

- 在左侧“文章总览”按钮的上方增加“时间线总览”按钮。
- 点击打开独立弹窗。
- 弹窗左侧有一根从上到下的纵向时间线，时间越往下越晚。
- 有事件的日期在线上显示一个小圆点；圆点左侧显示月份、日期，右侧显示该日各件事情的标题。
- 年份独立显示在窗口最左上角，不放到时间线上。
- 同一天多件事按“两行、无限列”向右延续排列，不能改成标题纵向无限堆叠。
- 鼠标位于该日事件标题区域时，滚轮使该区域左右滑动；鼠标在其他区域时，滚轮使整体时间线向上/下移动。
- 时间线最中间的日期视为“选中”；该日期稍微放大，并有半透明背景突出显示。
- 时间线最下端使用向下的箭头结尾。
- 年份和月份增加空心方块分隔节点，标题比事件标题稍大；线上日期仍用圆点，每个事件标题也有小圆点提示。
- 未知月份的文章归入年份节点；未知日期的文章归入月份节点，不再伪造具体日子。
- 整月或整年没有任何文章时，不生成对应分隔节点。

当前规则：左上角年份跟随居中节点；标题点击打开独立只读回忆；年/月未知文章按上面的补充归入分隔节点。年份和月份只表示分类，不代表未知文章发生在该年/月的第一天。

## 2. 随机回忆

- 在左侧增加“随机回忆”入口。
- 点击打开独立弹窗，随机显示一篇文章。
- 中间是带背景的纯文字阅读区。
- 中下部分显示毛毡板照片栏，沿用当前阅读模式的排版与照片板体验。
- 随机展示不修改文章正文。当前提供“再看一篇”，范围为全部未删除文章，不受主列表筛选影响；多篇时避免连续重复，只有一篇时禁用换篇按钮。

## 3. 右上角功能区收起与展开

- 对当前右上角四个功能增加整体收起按钮。
- 展开状态下，收起按钮位于这些功能按钮的最左侧，箭头朝右。
- 点击后，通过一小段动画收起全部四个功能。
- 收起后，右上角最右侧只留下一个朝左的箭头。
- 点击朝左箭头应展开功能区，形成可逆的收起/展开交互。
- 不把此交互改成单独隐藏某一个功能；按钮具体对象以开发时实际右上角四项为准。
- 当前四项为浅色主题、深色主题、数据文件夹、保存。180 毫秒收缩与淡出，记住收起状态，Ctrl+S 快捷键始终可用。

## 4. 人物档案与人物标签（v1.5 已实现）

记录日期：2026-10-30。本节需求已在 v1.5 实现。程序 1.5.0，schema v4；具体操作与边界见 PEOPLE.md，Windows 实机显示待验收。

### 人物档案入口与列表

- 左侧新增“人物档案”按钮，点击打开弹窗。
- 弹窗中间顶部放搜索框，下方排列一个个人物竖向矩形卡片。
- 卡片上方是圆形头像；初始使用绘制的人物剪影标志作为占位头像，下方显示姓名。
- 搜索用于查找人物，按姓名、代号匹配。
- 点击人物卡片后，弹窗切换到对应人物的详细档案，并提供返回列表入口。

### 人物详细档案

- 自上而下：头像、姓名、代号、出生年月日、相遇时间、相遇方式。
- 字段下方单独设置“相关事件”区域，列出带有该人物代号标签的文章；这里按人物标签关联，不通过正文是否出现代号来猜测关联。
- 最下方一排操作按钮，顺序为“编辑、删除、置顶、星标”。
- 点击星标后，人物卡片右上角显示小星星；置顶与星标是独立状态。
- 提供新增人物入口，供档案和选择器共用同一份人物资料。
- 人物删除不得删除其关联文章；删除确认及关联解除的具体交互在开发时落实。

### 文章人物标签选择器

- 右侧工具栏新增“人物标签”按钮，与现有文章标签功能并列，入口只用一个按钮。
- 点击按钮打开与人物档案列表样式相近的弹窗，用于选择当前文章关联的人物。
- 点击人物卡片切换选中状态，选中时头像/人物图标变为当前主题色。
- 弹窗底部展示已选人物，按“两行、无限列”横向延续，并可横向滚动。
- 每个人物是一块小矩形，前面显示姓名，后面是叉号；点击叉号取消选择，同时更新上方卡片选中状态。
- 一篇文章可以关联多个人物，一个人物可以关联多篇文章；只建立关联，不复制文章。
- 普通文章标签与人物标签分开管理；相关事件按稳定的人物关联读取，修改姓名或代号后不能丢失关联。

### 人物代号快捷插入区域

- “人物标签”按钮右侧增加展开/收起控件（下拉箭头样式）。
- 点击展开后，在右侧新增一小块快捷区域，支持再次收起。
- 快捷项按“两列、无限行”排列，区域可纵向滚动；每项只显示姓名和代号。
- 点击快捷项，将对应人物代号插入当前文章的正文光标位置。
- “插入代号文字”与“选择文章人物标签”是两项操作；本次需求没有要求插入时自动添加标签，开发时不隐式联动。

### 开发约束与后续细节

- 延续现有主题、原生桌面界面、保存失败保留编辑的行为。
- 人物资料与文章人物关联需要持久化；实施时增加兼容现有数据的数据库迁移，禁止删库重建。
- 人物资料和关联如何进入 EPUB 导入导出、GitHub 文章包，以及头像上传、模糊日期、代号重名等规则，见 PEOPLE.md：EPUB/GitHub 文章包携带关联人物；日期可留空或部分填写；代号唯一。头像目前仅默认剪影，不支持上传。
