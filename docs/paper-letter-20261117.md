# 纸间来信主题

在右上角「外观与主题」中选择「纸间来信」。这是浅色主题，软件会记住选择，切回电台等深色主题后也能直接重新选择。

- 米黄色信笺、细纸纤维纹理、左侧装订线和页角折纸均由 Qt 原生绘制，没有新增素材或字体依赖。
- 正文横线根据可见文字实际排版的基线绘制，跟随局部字号和滚动，不改变文字格式与段落间距。空白区域补充横线。
- 页脚有植物简笔画、短句和邮戳。空间不足时装饰区可以收缩；装饰不会接收鼠标操作。
- 照片板使用暖色纸纹和胶带装饰，保持照片的原比例、小卡片尺寸与头像排除逻辑。
- 歌词使用浅色便笺与深色文字，保留原有歌词字体、同步和译文。
- 信笺、横线、邮戳和短句都属于窗口绘制，不写入正文、不进入 EPUB。原默认字体与局部格式保留，其他主题仍可正常使用。季节背景偏好也保留，切回原主题后恢复。

验证覆盖：信笺主题的选择与重启记忆、电台往返切换、局部格式与保存 HTML、字体基线与滚动、照片比例、最小窗口和歌词共存、EPUB 无装饰导出。另复查现有字体、电台与日历检查，并在 Windows 临时数据窗口查看主题和字体弹窗。
