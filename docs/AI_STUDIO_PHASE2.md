# AI 工作室 · 第二阶段

日期：2026-11-02。基于 1.7.5-beta 的本地开发，未重新发布安装包。

## 使用

1. 重新打开桌面“NorthDiary 脚本版”（`D:\NorthDiary-v1.5\start.cmd`）。
2. 左上角进入 AI 工作室，打开 API 设置。
3. 从 DeepSeek 开放平台创建 API Key，粘贴后点击“应用密钥”。确保 API 账户有可用余额。
4. “测试连接 / 刷新模型”使用模型清单接口，不发送文章或生成回复。
5. 选择功能、文章和自定义要求，点击生成或发送。核对所示文章、功能提示词、历史消息及完整请求后，点击“确认并发送”。

默认使用 `deepseek-flash`，关闭深度思考，最大输出 8192 Token；可在设置页选择模型、深度思考和输出上限。模型清单会在测试连接时刷新。
接口固定为 DeepSeek 官方 `https://api.deepseek.com`，不需要用户编辑代码或配置其他提供商。

## 全选

文章选择器中的“全选当前结果”勾选当前分类、标签、时间线空间及搜索条件共同匹配的全部结果，保留之前已勾选的其他文章。无筛选时选择全部已确认且不在回收站中的文章；不会自动勾选。

## 提示词与参数

四个模块分别使用功能提示词：赏析、分析、创作和自由对话。分析区分事实、推测和未知，创作明确标记虚构。
类型、语气、视角、篇幅及用户要求合并为当前请求的指令。模型、深度思考和最大输出属于请求参数。
这些设置不会修改 DeepSeek 网页偏好或训练模型；本应用不读取网页聊天记录。
当前没有联网搜索、附件、人物档案或其他日记的自动读取工具。

## 对话与授权

- 四个模块有各自的本地对话列表；“新对话”不携带其他对话历史。
- 完整的用户问题和最终回复会随同一对话的下一次请求发送，发送预览可以逐项检查。
- 历史保存在本地数据库，重启后可以从下拉列表主动打开。启动不会自动选中旧对话或文章。
- 更换文章范围会切到新对话，旧对话保留。原文内容、标题、日期或范围变化时，下次发送将提示开启新对话并排除旧历史。
- 预览包含文章全文、指令、系统功能提示词、实际历史和不含密钥的完整 JSON 请求。实际发送使用预览时冻结的同一份请求内容。
- 中断、失败、输出截断的回复不会自动作为完整历史继续发送，但原始记录与已接收内容保留，可复制或重新生成。
- 重新生成会新增请求，保留旧回复。长内容不会被静默截断；客户端请求上限为 8 MiB，模型上下文不足时提示减少内容或新建对话。

## 密钥

Windows 当前用户 DPAPI 加密存储于 `%LOCALAPPDATA%\NorthDiary\device-secrets\deepseek.credentials`，与日记数据库分离，不进入日记备份、GitHub 文章包或源码。
取消“在本机安全记住密钥”后，密钥只保留至本次应用退出，旧的本机密钥文件会清除。
密钥应用后输入框清空；不会出现在请求预览、对话、日志或普通设置文件中。其他设备需分别配置。

## 流式与用量

使用 Qt 原生异步网络、TLS 校验与手动重定向策略。主界面不等待同步网络读取，停止会立即中止客户端连接；已产生的服务用量仍可能计费。
断网、认证失败、余额不足、频率限制和服务繁忙有明确提示，不自动重试，以免重复请求。
每次请求记录模型、时间、状态与接口回报的输入/输出 Token。服务未回报时显示用量及费用未知，不按字数虚构结算量。
费用区间参考 2026-11-02 官方美元峰谷价，不猜测节假日；未知模型不估价。参考区间与实际账单可能有差异。

## 数据与阶段边界

schema v7 → v8 迁移先保存数据库快照，新增 `ai_conversations` 和 `ai_turns`，原文章表不变。
对话、回复与请求用量独立于原始文章，不自动写回日记。
独立 AI 作品入库、富文本编辑、作品版本库、EPUB 导出和 Android 适配继续留待后续阶段。当前“保存作品”“编辑”按钮仍禁用。

## 已做验证与限制

- 本地真实 HTTP/SSE 协议测试：分片 UTF-8、心跳、用量尾包、两轮上下文、预览与实际请求一致、取消不发送、重新生成保留、授权范围隔离、原文变化、新建对话、部分回复保存、保存失败恢复。
- Windows DPAPI 使用临时占位密钥在正常用户上下文验证通过；受限测试沙箱内单独跳过该项。
- 实际官方 HTTPS 模型接口用明确无效的占位密钥探测，TLS 可用并返回预期认证失败；未使用真实 API Key 或私人日记做模型生成验收。
- 预览截图使用虚构文章与标注的演示回复，不代表真实 DeepSeek 生成结果。
