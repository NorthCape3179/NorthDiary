# 网易云免插件播放进度适配

在 SMTC 只提供歌名和播放状态而缺失时间轴时，后台读取正在运行的网易云 `cloudmusic.dll` 两个播放数值：当前秒数和总时长；SMTC 继续提供曲目、播放/暂停及速度。有完整 SMTC 时间轴时仍优先使用系统信息。

当前明确适配：网易云 3.1.41.205529 x64，DLL SHA256 `7f667f876caf94bc3dac3b0070d3e495117005fafdcf18b6aaa51eb004edac8c`，映像大小41054208。模块相对地址为当前秒数 `0x21A74D8`、总秒数 `0x2214778`；每次从动态模块基址计算，兼容 ASLR。

只用 Windows Toolhelp 枚举 `cloudmusic.exe` 的模块，申请 `PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_VM_READ`，每次仅读取2个8字节double；不申请写入/注入权限、不遍历堆、不扫描未知内存、不读取账号、Cookie、客户端数据库或音乐缓存、不启动HTTP端口、不安装网易云插件、不增加依赖。

从所有网易云子进程中选择持续更新的有效数值，首次至少两次样本校验范围、总时长稳定性及播放时进度递增；锁定后直接读取。暂停由SMTC控制冻结显示，拖动按新数值立即定位；切歌清除锁定重新校验，进程重启重新枚举，关闭歌词或退出软件关闭所有句柄。窗口被遮挡、最小化不影响该读取途径。

按DLL内容指纹识别，未知构建明确提示“当前网易云版本尚未适配免插件进度”，不盲套旧地址。不保证未来网易云版本；新增构建需单独核对布局及有效数值。正常用户权限优先，权限不足给提示，不自动请求管理员或安装组件。

位置数据参考（本模块为独立标准库实现，不引入项目的API、账号、数据库或播放器部分）：

- https://github.com/hanbinhsh/NetEase_Cloud_Music_Local_API/blob/main/offset_cache.json
- https://github.com/hanbinhsh/NetEase_Cloud_Music_Local_API/blob/main/README.md

本机只读验证：连续6次读取，首帧校验后取得264.763、265.353、265.943、266.533、267.163秒，总时长恒274.045秒。未控制实际播放器暂停或拖动，相关交互由用户验收。不进行全量测试。

本更新不安装此前下载的BetterNCM/InfLink-rs。脚本版重启生效，独立EXE未重新打包。
