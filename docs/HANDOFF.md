## 当前功能与已确认交互

### 文章列表、置顶、排序

- 三栏窗口，左列表、中编辑、右属性/照片板。
- 左侧模式：全部文章（默认，跨日期）、所选日期、最近打开；搜索、分类、普通标签筛选可组合。
- 最近打开最多200篇，保存在 ui.ini；右键可“移出最近打开”，只去掉历史，不删除正文，再从其他入口打开会重新加入。
- 右键文章：置顶/取消置顶、删除（移入回收站）；最近模式额外“移出最近打开”。右键操作针对目标文章，不是误操作当前编辑文章。
- 多文章置顶；顶部独立细工具栏里是自行绘制图钉；置顶始终优先。
- 排序：创建最新/最早、修改最新/最早、标题升序（字符序，非拼音）、手动。默认创建最新，记住选择，置顶组内部也按当前规则排序。
- **排序控件已从左侧移入“文章总览”弹窗。** main_window 中仍有隐藏 sort_combo 作为状态/接口，不能误以为没完成迁移而重新显示。
- 左下角“文章总览”在“回收站”上方：跨日期搜索、排序、列表显示日记/创建/修改时间，双击或点打开回到编辑。排序同步主列表。
- 手动排序时条目只能在框内上下移动，浮层68%不透明、浅灰描边；下方排列不动，松手才落位。置顶/普通区分别排序，过滤时仅调整可见位置。其他排序及最近模式不允许手动拖动。

### 日期与时间轴

- 自定义日期控件 DateInput：直接输入 `2026-07-15`、`2026/7/15`、`20260715`；Enter或失焦确认；校验错误保留原日期。
- 小日历按钮打开 DateDialog：自绘42格、年月跳转、今天/取消/确定，不再用内置 QCalendarWidget 的旧弹窗。
- 文章日期控制背景季节。时间轴是浏览日期的入口，不应意外改写文章日期。
- **时间轴按下不缩放；拖动前后三天内保持原刻度，超过三天才缩放**；指针连续移动、超界刻度轴跟随，松手提交筛选。
- 右侧日期范围按钮动态显示下一动作“全部日期 / 当前日期”，可以反复切换；“当前日期”指当前文章日期（不是强制今天）。已测试多次来回。

### 分类与标签

- **分类现在单选**：右侧下拉、“＋”新建；未分类选项；与左侧筛选共用分类目录。
- 底层旧 schema 仍支持分类关系多对多，但 UI 每篇只保留一个。旧文章若多分类，控件显示最后一个，下次保存按单分类规则保存。不要恢复旧的逗号多分类输入。
- 标签多选：普通标签进入可复用下拉和左侧筛选；临时标签只属于本篇、保存重开仍保留、不进入公共下拉。加号菜单选择普通/临时；胶囊×仅去掉关联。

### 照片与附件

- 正文只有 `ndiary-image:附件ID` 的可点击小引用，不把大图片塞进段落。引用单击仍可打开大图。
- 右侧是毛毡照片板：相纸白边、略宽下边、阴影、不同尺寸、稳定的轻微倾斜；悬停放大。
- **照片板单击只选中，相纸边整块变主题色；双击才开大图。** 不要恢复旧单击就弹窗。
- 选中才显示图片操作：跳到引用位置、编辑图注、在光标处插入引用、移除引用（保留图片）。图片导入复制托管，原文件不动。
- 大图对话框支持缩放/适应窗口/前后翻图/Esc。
- 普通附件基础管理存在，完整打开/移除等尚待完善。

### 回收站

- 左下独立入口，中央弹窗按行显示删除文章和日期/删除时间，下方可预览；行尾恢复、永久删除。
