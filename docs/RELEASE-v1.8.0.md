# NorthDiary v1.8.0

相较于 v1.7.5-beta，本版新增 AI 工作室、网易云同步歌词和秋日湖畔，并改进 Windows 脚本启动与文章列表交互。

- **AI 工作室**。接入 DeepSeek，支持流式对话、停止和重新生成，以及文章点评、分析和故事创作。可按分类、标签或搜索结果选择文章，发送前确认所选原文。回复支持 Markdown 表格和加粗。
- **AI 作品库**。保存与编辑生成内容，保留历史版本和原文关联，支持 TXT、EPUB 导出，以及另存为普通文章。
- **同步歌词**。根据 Windows 媒体会话识别网易云当前歌曲，查询网易云歌词及 LRCLIB，在有可用进度时同步显示原文和译文。支持字体、字号和刷新。网易云的兼容进度读取仅适用于受支持的版本。
- **秋日湖畔**。独立的分层像素场景，包含随风摇动的枝叶、不同远近幅度的水面倒影、落叶、落水波纹和漂浮渐隐。默认铺满工作区，可在顶栏暂停、切换铺满、打开设置或开启居中的双语歌词。
- **界面与启动**。左侧文章栏的悬停提示只作用于未选中的文章，已选项保持选中色。Windows 脚本优先加载与 Python 匹配的运行库，降低第三方 OpenSSL DLL 冲突。
- **数据升级**。SQLite 数据库升级至 schema v9，升级前保存快照。

## 获取与运行

下载 `NorthDiary-v1.8.0-script.zip` 并完整解压，使用 Windows 10 / 11 x64 和 Python 3.11–3.13 运行 `start.cmd`。首次运行会联网安装依赖。已有虚拟环境可先执行 `.venv\Scripts\python.exe -m pip install -r requirements.txt` 更新依赖。此版本提供脚本版 ZIP 与 GitHub 源码归档。

## 验证

Windows 原生窗口检查通过，覆盖版本显示、秋日湖畔加载、双语歌词桥接和落水波纹。全量检查仍复现 v1.7.5-beta 已记录的 GitHub 连接界面、EPUB 反斜线路径样例及顶栏快速折叠时序断言失败。顶栏时序项单独复测通过。
