# 人物照片与头像引用

- 人物档案 → 编辑：选择头像图片，自动居中裁切为圆形显示；“恢复默认头像”切回剪影。取消编辑不会保存头像变动。
- 人物详情最底部 → 照片：支持一次添加多张、双击查看、上一张/下一张、缩放、设为头像和移除照片。移除不会删除电脑上的原文件或已设置的头像。
- 编辑文章时展开人物引用栏，在上方选择“引用代号”或“引用头像”，然后点击人物。头像引用为透明底圆形 PNG，正文显示 24 × 24 像素；未设置头像时会提示先设置。
- 引用的是插入时的头像副本。更换头像、移除人物照片或删除人物档案，不会改变原文章中已经插入的头像。支持撤销/重做、重新打开、阅读预览、回忆阅读和 EPUB 导入导出。
- 人物照片保存为最长边不超过 2000 像素的 JPEG 浏览副本，头像不超过 256 像素，保存在本地数据库中。支持 PNG、JPEG、WebP、BMP、GIF（静态首帧），应用读取照片方向；原文件保持原样。
- 每个人物最多 100 张照片，总编码数据不超过 32 MiB；单个输入文件需小于 32 MiB。添加一批照片失败时整批不写入。
- schema v9 → v10 新增 person_media 表；旧库升级前生成 before-v10-*.sqlite3 快照，不修改已有文章/人物记录。完整 .ndiary 备份包含全部人物图片。
- EPUB 和 GitHub 原生文章包会携带所选文章关联人物的头像及照片，仍受现有清单 8 MiB/文章包大小限制。图片较多时导出会明确报错；完整保存全部人物资料请使用 .ndiary 备份。旧程序不支持读取本次升级后的数据库或带图片的人物资料，应使用新版程序。
