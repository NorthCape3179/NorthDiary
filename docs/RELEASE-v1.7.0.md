NorthDiary v1.7.0 — 首个 Windows 安装版

Windows 10/11 x64，安装后无需另装 Python。下载 `NorthDiary-Setup-v1.7.0.exe`。
安装时可选择程序位置；默认沿用原日记数据目录。首次没有默认数据时，可以选择已有数据目录或新空目录。
更新前建议在软件中导出 .ndiary 备份。升级到 schema v4 后，旧程序不能直接打开升级后的同一数据库。

主要功能：
- 本地图文日记、附件、分类、普通与临时标签、自动保存及回收站。
- 时间线总览、模糊日期、随机回忆、阅读模式和季节背景。
- 人物档案、关系标签、文章关联及人物代号快捷插入。
- EPUB 导出与 NorthDiary 专用 EPUB 导入；GitHub 私有数据仓库的文章包手动上传下载。
- 深浅模式与多种配色、可折叠工具栏、文章总览分类排序和右键删除。
- 分区软件详情页，统一版本 v1.7.0；采用用户提供的程序图标。

开源：原创部分 AGPL-3.0-or-later。对应项目源码、图片、图标、测试与构建脚本见
`NorthDiary-1.7.0-source.zip`；安装包内 `_internal/licenses` 也提供该源码包。
第三方声明及其对应版本源码入口见源码中的 THIRD_PARTY_NOTICES.md。
个人日记、照片、数据库、备份和登录凭据不包含在发布文件里。

验证：安装、独立 EXE 启动、覆盖安装及卸载保留合成数据测试通过；
数据库、人物、图片、EPUB 导入导出、背景和图标诊断通过。软件详情页 4 项回归通过。
原完整源码测试共164项：160通过、2项已知失败、2项跳过，并非全绿。
已知测试失败为 Windows GitHub UI 测试替身 save 方法及 EPUB 反斜线路径拒绝测试。
