# NorthDiary v1.7.0

首个 Windows 安装版，将本地图文记录、时间线回顾、人物档案和文集导出集中在原生桌面窗口中。

## 下载与安装

- **安装包**：[NorthDiary-Setup-v1.7.0.exe](https://github.com/NorthCape3179/NorthDiary/releases/download/v1.7.0/NorthDiary-Setup-v1.7.0.exe)，约 65 MiB，面向 Windows 10 / 11 x64，无需另行安装 Python。
- **对应源码**：[NorthDiary-1.7.0-source.zip](https://github.com/NorthCape3179/NorthDiary/releases/download/v1.7.0/NorthDiary-1.7.0-source.zip)。
- **文件校验**：[SHA256SUMS.txt](https://github.com/NorthCape3179/NorthDiary/releases/download/v1.7.0/SHA256SUMS.txt)。

安装时可选择程序位置。启动时默认沿用已有的默认数据目录；首次没有默认数据库时，可选择已有日记目录或新的空目录。安装包尚未数字签名，Windows 可能显示“未知发布者”。

## 更新内容

### 安装与开源

- 提供独立 Windows 安装程序、快捷方式及卸载功能。
- 集成 NorthDiary 图标，统一版本显示为 v1.7.0。
- 增加首次启动的数据目录选择，程序文件与个人日记分别保存。
- 采用 AGPL-3.0-or-later 开源许可，提供对应项目源码、图片、图标、测试及构建资料。安装目录 `_internal/licenses` 也包含项目源码 ZIP 和许可证。

### 文章与人物

- 文章总览增加右键移入回收站、分类排序和分类筛选。
- 人物档案增加普通与临时关系标签，支持选择和新建。
- 优化关系标签与选择弹窗的深色主题显示；临时标签通过颜色区分，去掉文字后缀。
- 完善 EPUB 与 GitHub 文章包中的人物及关系资料交换。

### 时间线与界面

- 缩小时间线总览节点和卡片，提高单屏可见的信息量。
- 右半区纵向滚动；左半区仅在事件超宽时提供小幅横向滚动。
- 调整主界面时间轴拖动时的更新方式，减少重复加载与闪烁。
- 主题区改为深浅切换按钮和配色选择框。
- 随机回忆移至右上角数据文件夹之后，随工具区一起折叠。
- 新增分区软件详情页，入口位于顶栏最右侧。
- 保留独立的虚构展示数据生成脚本。

## 保留的主要功能

本地图文日记、自动保存、分类标签、搜索排序、照片板、回收站、模糊日期、时间线总览、随机回忆、人物档案及代号插入、季节背景、多种主题、EPUB 导出、NorthDiary 专用 EPUB 导入、GitHub 私有数据仓库的文章包手动上传下载，以及完整 `.ndiary` 备份导出。

## 数据兼容性

更新前请在软件内导出 `.ndiary` 备份并正常关闭程序；更新时沿用原数据目录。

人物功能使用 schema v4，首次升级前会生成数据库快照。旧程序不能直接打开升级后的同一数据库；回退须使用升级前快照的副本数据目录。

EPUB 导入只接受 NorthDiary 专用格式；v1.1 旧导出文件须用新版重新导出。未在正文引用的独立附件不属于 EPUB 交换范围。GitHub 功能为手动文章包交换，每包最多 20 MiB，不提供自动双向同步。

## 验证范围与当前限制

安装、独立 EXE 启动、覆盖安装及卸载保留合成数据检查通过；数据库、人物、图片、EPUB 往返、背景和图标诊断通过。软件详情页 4 项回归测试通过。

源码回归测试共 164 项：160 项通过、2 项已知失败、2 项跳过。已知失败涉及 Windows GitHub UI 测试替身的 `save` 方法和 EPUB 反斜线路径拒绝测试。未在完全干净、未安装 Python 的 Windows 虚拟机中完成验收。

自助备份恢复界面、自动备份、PDF 导出和自定义人物头像尚未提供。
