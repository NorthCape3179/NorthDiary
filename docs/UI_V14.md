# v1.4 界面功能

## 时间线总览

入口在左侧“文章总览”正上方。弹窗按日期从早到晚排列，独立年份标题固定在左上角，跟随中间选中节点更新。中间节点以浅透明底色与稍大的文字强调；日期圆点沿纵轴排列，轴末端为向下箭头。

每个有记录的年份、月份各生成一个空心方块分隔节点，字号分别大于普通事件。整年或整月没有记录就不生成节点。仅知道年份的文章显示在该年节点右侧；仅知道月份的文章显示在对应月节点右侧，附“月份未详”或“日期未详”说明，不给文章补造月/日。精确到日的文章在日期圆点右侧排列。极少数无效旧日期归入独立“日期未详”节点，不改数据库日期。

同节点标题按两行、无限列排列，每个标题有小圆点，长标题省略并可悬停看全。事件区域内滚轮横移该节点的标题，其他位置滚轮纵移时间轴。横向位置按节点独立保留；窗口扩大后自动约束偏移。标题点击打开只读回忆，时间线保持原位置。支持上下/Home/End/PageUp/PageDown 浏览节点，左右浏览所选节点的标题，回车打开第一个事件；无文章的分隔节点回车不做操作。

绘制仅处理可见节点和标题，不为每篇文章创建一个常驻控件。不按时间跨度补出大量没有事件的日期、月份和年份。

## 随机回忆

左侧“随机回忆”打开独立阅读弹窗。随机范围为全部未删除文章，忽略主列表的搜索、日期、分类和标签过滤；多篇时不会连续抽到同一篇，单篇时禁用“再看一篇”。没有文章时显示空状态。

正文以只读纯文字显示，正文内图片和照片入口文字从阅读文本中移除；中下方复用阅读模式的横向毛毡照片板，悬停/选中/双击大图行为保持一致。无图片时不显示空照片板；缺失图片显示占位提示。背景使用文章季节和当前深浅主题，未知月份使用现有通用背景。

随机回忆和时间线内的回忆阅读共用 MemoryDialog。浏览不会切换主编辑器，不改文章、排序和“最近打开”记录。打开新弹窗前主界面先保存待处理编辑，保存失败则停止打开，保留原内容。关闭后销毁阅读/时间线/图片弹窗，避免隐藏窗口持续持有照片资源。

## 右上角功能收起

将原有浅色主题、深色主题、数据文件夹、保存四个控件放在共同的裁剪区域内，最左侧添加向右箭头。点击后在 180 毫秒内收缩宽度并淡出，箭头随整个区域靠右收起；最后只剩右上角最右侧的向左箭头。点击向左箭头反向展开。快速重复切换会从当前动画状态反转，不重建四个控件。

收起时关闭主题弹层并禁用隐藏区域，避免看不见的控件仍可操作；全局 Ctrl+S 保存快捷键保留。状态保存到 ui.ini 的 header_collapsed，重启后恢复。无数据库迁移。

## 验收边界

自动测试与 Qt offscreen 渲染可验证交互和几何布局；当前环境缺少中文字体和原始二进制背景，不能将其等同于 Windows 的中文字体、缩放、背景与触控板体验验收。背景文件在远端源码树中原样保留，未用占位图替代。
