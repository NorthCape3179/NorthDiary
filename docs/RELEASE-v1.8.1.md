# NorthDiary v1.8.1 更新公告

2026-11-14

这次主要补全文章排版和导出体验，新增 AI 记忆回顾，并继续调整秋日湖畔与 Windows 窗口。以下内容相较于已发布的 v1.8.0。

## 文章编辑与导出

- 编辑栏加入字体、字号及段落对齐控制，支持设置新文章的默认排版。
- 新增可搜索、勾选常用字体的字体选择器；字体可用性取决于内置字体及本机安装情况。
- EPUB 导出保留可移植的字体、字号、首行缩进和段落对齐格式。
- 导出文章列表支持标题／日期搜索、全选、取消、反选及顺序调整，筛选后保留已有勾选。

## AI 记忆回顾

- AI 工作室新增记忆回顾，可围绕选定文章整理主题或提问。
- 支持核对报告中的跨文章关联、打开来源文章并保存判断。
- 文章来源选择增加时间线与时间线之外的区分；复制与保存报告时整理展示内容。

## 窗口与秋日湖畔

- 加入统一的 Windows 窗口边框与标题栏处理，调整窗口控件和编辑区布局。
- 秋日湖畔增加湖面生物与氛围效果，调整近景枝叶、水层及倒影表现。
- 改进场景与桌面窗口间的设置传递，以及网易云播放进度兼容读取。

## 下载与升级

本次提供源码和 `NorthDiary-v1.8.1-script.zip` 脚本版，不提供新版 EXE。完整解压后，在 Windows 10／11 x64 和 Python 3.11–3.13 环境运行 `start.cmd`；首次启动会安装依赖。沿用已有虚拟环境时，先按 requirements.txt 更新依赖。

程序版本为 1.8.1；数据库仍为 schema v9。本次源码不包含个人日记、附件、数据库或登录凭据。更新前请导出备份。

## 验证情况

本次运行 62 项定向检查，覆盖版本与详情页、字体选择、排版、窗口、EPUB 和 AI 工作室。汇总单独复检结果后：59 项通过，1 项跳过，2 项旧测试未通过。

两项旧测试分别仍按 schema v8 之前的 AI 表集合做断言，以及在构造 v7 数据夹具时遗留 v9 作品表，导致重复建表。Windows 安全存储检查最初受执行环境限制，单独复检通过。AI 记忆回顾的来源范围校验和报告正文提取另行检查通过。

源码编译与待上传文件检查通过。本次没有重新运行全量检查，也未完成干净 Windows 环境的完整人工验收；历史 v1.8.0 的 GitHub 连接、EPUB 路径与顶栏时序等已知测试问题不在本次修复范围。
