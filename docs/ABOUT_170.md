# NorthDiary v1.7.0 软件详情

本机程序版本统一为 1.7.0。主窗口标题、应用版本信息、软件详情标题、版本标记、当前版本与项目信息均读取 `northdiary.__version__`。

顶栏最右侧增加圆圈 i 图标，独立于可折叠工具区，折叠后仍可打开软件详情。详情为原生 Qt 弹窗，包含固定品牌区、分区跳转按钮、可选择文字的滚动正文与关闭按钮，跟随八套配色。

正文保留品牌理念和叙述，补全文章管理、分类/标签、人物/关系、时间线、回忆、图片附件、EPUB、GitHub 手动文章包、本地数据及展示模式。界面框架标注为实际使用的 PySide6 / Qt；人物头像仍为默认剪影，自定义照片列为未支持。未来计划与当前功能明确区分。

页尾横线后显示作者 NorthCape、闲聊 Q 群 539241974、辅助 ChatGPT；“（其实是主力）”以小字号淡色显示。没有自动联系群聊、发送消息或访问项目仓库。

本轮不打包安装程序，不上传仓库，不读取或变更真实日记数据；数据库 schema 与 EPUB 格式版本不变。打开详情不额外保存、切换或重置当前文章；原有自动保存仍按原逻辑运行。

更新日志按项目文档补充 v1.0–v1.5 历史记录，提供页内跳转；当前版本仍为 v1.7.0。没有编造未记录的中间版本。
