# NorthDiary 1.5.2 · 2026-10-30

- 人物关系：多选普通/临时标签、选择/新建/移除，卡片与详情展示关系。
- 深色适配：关系标签、添加/移除按钮、下拉与新建弹窗，以及人物编辑布局优化。
- 文章总览：右键删除，确认后移入回收站，可恢复，相关列表同步刷新。
- 时间线总览：右半区纵向滚动；左半事件区仅溢出时横移，滚轮每格约 24 像素；窗口变宽后归零。
- 主界面时间轴：约 90 ms 合并拖动预览，松手立即切换；去掉先清空再加载，连续空日期仅更新日期与背景。
- 独立展示模式：虚构文章/人物/标签生成器及专用启动入口，不提交数据库。
- 数据库 schema v5；EPUB 原生清单 v3 携带关系资料，兼容旧 v1/v2。

升级前自动保存数据库快照；旧程序不能直接打开升级后的数据目录。

相关功能完成针对性测试及部分主题渲染检查。用户已体验时间轴改进，但实际卡顿和闪烁仍待进一步验收。

全量测试仍有已知未通过项：Windows GitHub 模拟凭据存储缺少方法；EPUB 反斜杠路径检查。无权限时符号链接测试跳过。真实账号授权、系统加密凭据及阅读器仍待验收。

目前通过 Python 源码运行，尚无安装程序、自助备份恢复或自动双向同步。
