# 本机 1.5.3 界面调整

## 时间线总览

保持弹窗大小，缩小节点、标题卡片、年份文字和间距。节点步长由 144 改为 112 逻辑像素，同样高度可显示约三成更多节点。双行事件、中心强调、点击打开回忆、键盘导航与原滚轮规则保留。

## 文章总览

右上角排序新增“分类排序”。选择后，其左侧出现分类下拉，支持全部分类、指定分类、未分类。全部分类下按分类排列，未分类置后；同分类内按标题、日期排列。新增分类列，分类筛选与搜索叠加。切回其他排序隐藏分类框、取消其筛选，不改变文章分类。分类模式不写入主列表不支持的排序键。原有打开文章和右键移入回收站保留。

## 主题

右上角仅显示一个深浅切换按钮及一个配色选择框。按钮切换深浅，配色框显示当前模式的选择：六套浅色、两套深色。两种模式分别记住上次配色；兼容现有 ui.ini 设置。重启恢复当前主题，收起工具栏仍可用 Ctrl+S 保存。

## 范围

本轮只修改本机程序与测试，没有上传仓库，没有修改个人数据库、附件或展示数据库。无新增数据库迁移。真实 Windows 缩放与操作体验由用户验收。
