# 本机 1.5.1：人物关系标签

人物列表卡片和人物详情显示关系。新增或编辑人物时，在“关系”下拉中选择已有普通标签，或点“＋”新建普通标签、临时标签；可多选，点 × 移除。

普通关系标签独立于文章标签，保存人物后可供其他人物复用；移除当前人物的标签不删除公共候选。临时关系标签只保存在当前人物，不进入其他人物的候选。取消编辑不会保存标签。人物资料与关系在同一事务保存，失败保留填写内容。

数据库升级至 schema v5，现有 v4 数据首次升级前自动生成 `backups/before-v5-*.sqlite3`。旧程序拒绝打开升级后的数据库。不要删除原数据库或将旧版直接指向升级后的目录。

关联人物的普通/临时关系标签随 EPUB 和 GitHub 文章包携带。新包清单为 v3，新程序继续接受 v1/v2 旧包。人物冲突时保留本机档案并生成副本；关系跟随对应档案。未关联到所选文章的人物仍不包含在 EPUB 中。完整 .ndiary 备份包含全部关系数据。

这是本机修改，未上传 GitHub。窗口和真实账号验收由用户完成。
