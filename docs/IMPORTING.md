# NorthDiary EPUB 导入（更新至 v1.5）

## 使用

用 v1.2 或更新兼容版本“导出 EPUB”，在另一份 NorthDiary 中点击“导入 NorthDiary EPUB”，选择该文件，检查预览数量后确认。仍可用普通阅读器阅读该 EPUB。

仅支持包含 `NorthDiary-EPUB` 版本 1 或 2 清单的本软件导出文件。不适配任意 EPUB、Word、PDF、Markdown 等外部格式。v1.1 及更早 EPUB 没有原生清单，需回到软件用新版重新导出，不猜测章节来重建数据。

v1.5 导出使用清单 v2，增加所选文章关联的人物资料；v1.5 兼容旧 v1 包，旧程序不能导入 v2。人物冲突与范围见 PEOPLE.md。

## 导入内容

- 标题、正文基础富文本、日记日期（包括未知月份和未知日期）、创建/修改时间、置顶状态。
- 人物档案与文章人物标签（清单 v2），未关联所选文章的人物不携带。
- 分类、普通标签和临时标签。已有同名分类/标签按名称复用。
- 正文实际引用的 PNG/JPEG/GIF；包括正文照片入口及旧式内嵌图片。图注和原文件名会保留，图片复制到本机 attachments，并生成新的附件编号、路径和正文引用。
- 新文章的手动排列位置按书中章节顺序追加到末尾；原有列表与排序规则不改动。

不导入主题、窗口设置、最近打开、回收站内容，也不包含正文未引用的独立附件。EPUB 交换不是 `.ndiary` 完整备份恢复。正文经白名单清理，保留基础格式，不能保证 Qt 的全部视觉排版原样往返。

## 重复与冲突

导入副本使用来源文章编号与内容指纹派生的固定 UUID。重复导入同一版本会跳过，即使导入副本后来被编辑或移入回收站，也不覆盖或自动恢复。原始文章在本机且内容相同也跳过；原编号已有不同内容时，新建“导入副本”。同一来源的不同修订会共存，不自动合并或选择较新者。这是手动导入，不是双向同步引擎。

永久删除导入副本后，可再次导入。内容指纹不包含书内图片文件名，因此调整章节次序或导出范围，不会仅因图片重新编号而重复导入已有内容。

## 文件格式

正常 EPUB 3 容器内新增 `EPUB/northdiary/manifest.json`，在 OPF manifest 中登记为 application/json，不参与阅读顺序。清单保存原生文章字段和正文、来源资源映射及 SHA-256；图片复用正常 EPUB 阅读资源，不重复附加另一套文件。

导入以原生清单为准，不反向解析阅读章节。第三方工具修改可见章节不会自动同步到清单，重新打包后也不保证兼容。格式标识与校验用于识别和检查数据，不是发布者的密码学签名。

## 写入与限制

导入先完整读取、校验和清理，再展示预览；确认后使用内存中已校验的快照，不重新读取可能被替换的源文件。正式写入期间重新检查本地重复状态。整个批次使用一个 SQLite 事务，写入失败回滚数据库并清理本次新图片，绝不覆盖已有图片文件。

拒绝路径穿越、重复 ZIP 成员、符号链接、加密成员、非法字段、未来格式版本、图片散列不符和缺失引用。清理脚本、事件属性和非托管图片路径。限制 1000 篇文章、5000 个图片引用、清单 8 MiB、单成员 32 MiB、解压总量 256 MiB；导出侧也应用相应限制。当前为界面线程内同步处理，大批量数据可分批导入。

不改变 schema v3，不迁移或替换整个数据库。进程强杀/断电仍需依赖 SQLite 的恢复机制，可能遗留尚未登记的新图片文件；这不等于完整备份恢复或断电零损失保证。
