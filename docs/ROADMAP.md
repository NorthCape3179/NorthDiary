## 后续：Android 与 GitHub 同步

- 保持本地优先，Windows 与 Android 各自保存数据；无需自建常驻云服务器。
- 提供“连接 GitHub”入口，点击后打开系统浏览器，在 GitHub 官方页面登录和授权，应用检测授权完成并显示连接状态。
- 优先研究浏览器授权后返回应用的体验；若采用设备授权，需要明确展示验证码步骤。具体授权流程须按届时 GitHub 官方要求验证，不能假定 PKCE 能免除其应用密钥要求。
- 应用不收集 GitHub 密码，不把应用机密或令牌写入源码、仓库、日志或普通导出包；访问凭据使用平台安全存储。
- 日记使用独立私有数据仓库，与 NorthDiary 源码仓库分开；首先提供手动同步按钮。
- 同步按文章唯一编号与版本信息处理，双方修改时保留冲突副本；删除使用删除记录传播，避免旧内容复活；不直接覆盖整个 SQLite 数据库。
- 评估图片和附件的容量、请求限制、网络失败与重试；大量视频不预设放入 GitHub。
- EPUB 用于阅读与成书；无损交换应使用带格式版本的专用数据包，保留标签、分类、日期精度、原始附件等信息。现有 `.ndiary` 备份与未来交换格式的关系需另行设计，不能把完整备份恢复直接当作双向合并。

本节是原生导入阶段的历史需求；v1.3 已推进 GitHub 连接和手动包传输，其余按上方当前状态执行。
