# AI 工作室 · 第一阶段

本文件是第一阶段的历史记录；当前第二阶段功能和使用方式见 `AI_STUDIO_PHASE2.md`。

基于 v1.7.5-beta 的本地 UI 开发，版本号暂保持不变，未重新发布安装包。

## 已完成

- 顶栏左上角“AI 工作室 / 返回日记”切换整个工作区，返回时保留原来的日记空间和编辑状态。
- 工作室主页、文字赏析、深度分析、故事创作、自由对话、AI 作品库、API 设置。
- 模块类型、语气、视角、篇幅、自定义要求；每个模块的输入在当前窗口内独立保留。
- 文章选择器覆盖时间线之内与之外的已确认文章，排除回收站和待确认文章。
- 标题/正文搜索、分类、标签及空间筛选；跨筛选保留勾选，取消不改变当前选择。
- 本次文章清单、移出范围、打开原文，以及正文和自定义指令的本地预览。
- 八套主题复用现有主题系统；较小窗口的工作区支持滚动。

## 阶段边界

本阶段不联网，无 DeepSeek 客户端，不收集或保存 API Key，不创建 AI 数据表。
生成、停止、复制结果、编辑结果、保存作品和连接测试暂时禁用并提供说明。
作品库展示分类、搜索与空状态，暂时没有作品保存、版本、删除、导出或文章转换。
Token 与费用显示“—”，不提供模拟用量或虚构生成结果。
文章选择和自定义要求仅保留在本次窗口内；关闭应用后不保存。

## 授权边界

打开工作室不会自动选择日记。选择器默认只读取列表元数据，用户主动搜索时使用本地正文筛选。
点击“查看本次范围”后，只查询当前所选且仍有效的文章正文，并重新读取最新内容。
不读取或附加人物档案、附件内容、其他日记。预览接受不形成可复用的发送授权。
当前没有实际对话，范围预览显示历史对话 0 条；后续联网阶段需要把实际历史上下文纳入预览。

## 验证

预览脚本 `work/preview_ai_studio.py` 使用临时数据库与虚构内容，不打开个人日记数据。
