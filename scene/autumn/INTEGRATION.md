# 秋日湖畔 · NorthDiary 接入说明

已接入 Windows 脚本版 NorthDiary 1.7.5-beta。顶栏入口位于“AI 工作室”后面，点击切换整个工作区，再点“返回日记”退出。场景按需加载，不影响日记启动；加载失败时可重试或直接返回。

## 当前功能

- 使用附件 0.1.0 的独立图层、落叶、风、水面、芦苇与枝条系统，默认轻动态 30 FPS。
- 页面采用桌面布局，让画面占用剩余工作区。提供暂停、静态/轻动态/完整动态、风力、落叶数量、水面波纹、图层与落水调试，以及参数 JSON 导出。
- “铺满场景”在工作区内隐藏介绍和工具栏；画面下方可退出，也可按 Escape。NorthDiary 原有 F11 全屏保持可用。
- 场景的“同步歌词”与顶栏音乐开关联动，使用同一个原生 MediaObserver / LyricsLookup，不创建第二套播放器识别或歌词请求。
- 歌词移至下半部的湖面留白，当前原文与译文居中，上句在右上、下句在左下、时间在右下；带原文、当前译文及相邻歌词；同步使用原生播放时间与偏移设置，默认融合像素 27px。顶栏“歌词设置”的字体/字号修改也作用于场景；日记歌词小开关移至置顶、背景图按钮之后。
- 没有准确进度时显示等待信息，不伪造自动同步。未提供译文的歌保留原文。
- 切换页面后停止场景 ticker，返回时继续；保留手动暂停与品质选择。

## 代码与构建

本目录为可继续开发的 TypeScript 源工程；运行时使用 `northdiary/assets/autumn-scene/` 中已编译资源。普通用户不用安装 Node.js、启动服务器或配置 API。

```powershell
npm ci --ignore-scripts
npm run build
```

构建后将 `dist/` 文件复制到 `northdiary/assets/autumn-scene/`，保留相对目录。Python 接口为 `ui/autumn_scene.py`，静态资源服务为 `services/scene_assets.py`。

页面通过 QWebEngineView 内嵌，QWebChannel 只桥接歌词开关与宿主推送的播放数据。静态服务仅绑定 127.0.0.1 随机端口、随机路径，仅允许工程资源与四种内置字体；不提供目录列表、写入或日记文件。内嵌页面禁止外部网络请求，播放器和歌词网络访问仍由原有 Python 服务负责。关闭窗口后回收页面与本地服务。

## 当前边界

0.3.0在0.2.0基础上新增近景密叶树冠、远/近水面漂叶层；真实落水触发双圈波纹、45秒漂浮、4秒渐隐。0.2.0已替换粗糙测试底图、枫枝与岩岸，采用独立像素美术资源，详情见ART_ASSETS.md。静态远景底图内的山、林尚未拆成可动层；整个枫枝轻摆，额外独立叶片可脱落。当前只有秋日湖畔，尚未加入其他季节、昼夜、天气或音频频谱。场景参数目前仅在本次窗口中保留，导出 JSON 不会自动写回默认配置。

本次只做 TypeScript 构建、桥接消息校验和短暂原生启动检查：按钮顺序、双语数据进入页面、字体、页面切换暂停及返回。未做长时间性能验收，未调用 DeepSeek，也未改动个人日记、测试数据或数据库结构。
