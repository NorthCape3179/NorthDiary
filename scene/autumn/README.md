# NorthDiary · 秋日湖畔 0.3.0

独立动态像素湖畔场景，已接入 NorthDiary Windows 脚本版。此次更新重点是分层美术、构图、歌词可读性和桌面按钮位置，原测试版说明保存在 README.original-test.md。

## 直接使用

正常启动 NorthDiary，点击 AI 工作室右侧的秋日湖畔按钮。无需 Node.js 或 API Key。日记中的歌词小开关位于置顶、背景图按钮后面，右上角为歌词设置；场景内的同步歌词与同一开关联动。

## 独立预览与开发

附带 dist 构建产物。在 dist 目录用任意本地静态 HTTP 服务预览，例如 `python -m http.server 8080`，然后打开终端显示的本机端口。不要双击 HTML 使用 file://。

重新构建需要 Node.js 22.12+：

```sh
npm ci --ignore-scripts
npm run build
```

将 dist 内容复制到 NorthDiary 的 northdiary/assets/autumn-scene 中。未连接原生宿主时，同步歌词按钮显示原创排版示例，不会伪装成真实播放器歌词。场景可独立启动，真实播放数据由 NorthDiary 原生服务提供。

## 0.3.0 调整

- 上部新增独立密叶近景树冠，原悬枝放大，形成前后两层；下方岩岸恢复完整显示。
- 远处/近岸两个水面漂叶层，打开即有18片漂叶；浮在水面的叶片缓慢漂动、停留、渐隐后循环补入，不抢占空中落叶池。
- 真正从空中落水的叶子产生双圈扩散波纹，停留45秒后用4秒淡出。已有落水演示用于观察过程。
- 新增三层均可在场景设置的图层列表里独立开关。水域遮罩与石头遮挡一并调整。

## 素材与层级

新的山湖底图、透明枫枝和透明岩岸位于 public/assets/autumn_day；PNG 保留原始分辨率和 alpha，可单独替换。枫枝轻摆、独立叶片脱落、漂叶、波纹与芦苇继续由 PixiJS 驱动。使用 480×270 逻辑坐标、三倍渲染画布与 nearest 采样，避免将精细素材压成粗糙的大色块。

美术生成方法、提示词、真实拆分程度与文件尺寸见 ART_ASSETS.md；原生接入和当前边界见 INTEGRATION.md。普通页面不显示 FPS、分辨率与测试素材说明；调试信息收在场景设置里。

## 当前边界

当前仅秋日午后。静态底图中的山、林不是独立可动层；枫枝绘画本体是一个透明部件，独立运动和脱落的是额外叶片。未做其他季节、天气、频谱，也未做长时间性能验收。场景参数保留于本次会话，导出 JSON 不会自动覆盖默认配置。

旧 scripts/generate-assets.mjs 是原测试素材生成器，运行会还原旧默认配置，请勿用它覆盖新美术。新的源美术不由该脚本生成。
